# Contributing to ViceCity Studio

Thank you for wanting to contribute to this project! You can share ideas, fixes, and new features to improve the user experience.

## How you can contribute

- report bugs
- suggest improvements
- add new components
- refine styles and UX
- review and fix code issues

## Recommended workflow

1. Clone the project.
2. Create a new branch for your change.
3. Install the dependencies:

```bash
npm install
```

4. Run the app locally:

```bash
npm run dev
```

5. Make your changes and verify everything works as expected.
6. Run a production build before submitting your changes:

```bash
npm run build
```

7. Open a clear Pull Request and describe what you changed.

## Recommendations

- keep the code simple and readable
- follow the project's existing conventions
- do not add unnecessary dependencies
- test your changes before submitting a PR
- keep a consistent style that matches the app's retro design

## Main project structure

```text
src/
  components/
  pages/
  data/
  assets/
```

## PR guidelines

- clear description of the change
- screenshots when relevant
- short, explicit, and useful message
- confirm that the build passes

If you have a good idea, open an issue or pull request and we will discuss it together.
